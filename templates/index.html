Endpoints

RESTful JSON API. Base URL: https://ethioforex.api

GET /api/v1/rates All banks, all currencies — current snapshot GET /api/v1/rates/{bank} Rates for a single bank (e.g. cbe, dashen, awash) GET /api/v1/rates/{bank}/{currency} Single rate pair — e.g. /cbe/USD GET /api/v1/history/{bank}/{currency} 30-day historical rates for a bank/currency pair GET /api/v1/compare/{currency} Compare a currency across all 8 banks side-by-side GET /api/v1/banks List supported banks with slugs and metadata POST /api/v1/subscribe/webhook Register a webhook URL for rate change alerts — coming soon
